# 🎮 Offshore Estudy Game

Jogo educativo, gratuito e de código aberto sobre engenharia offshore e submarina — exploração de petróleo, equipamentos subsea e operações em águas profundas — em uma jornada de estudo no seu próprio ritmo.

**[▶ Jogar agora](https://paulobuchaul-lang.github.io/offshore_study_game/)**

## Sobre o projeto

O Offshore Estudy Game transforma o aprendizado de temas técnicos de engenharia submarina em uma experiência leve, no estilo visual retrô 16-bit, sem perder o rigor técnico do conteúdo. Feito para quem precisa entender equipamentos e processos offshore no dia a dia de trabalho, sem depender de treinamentos caros ou demorados.

## Funcionalidades

- 🎛️ **Cockpit Mestre** — cabeçalho fixo com navegação, tema e progresso, presente em todas as telas
- 🌗 **Tema Abissal / Daylight** — alterna entre modo escuro e modo claro de alto contraste
- 🔊 **Áudio 16-bit sintetizado** — efeitos sonoros e trilha chiptune opcional, gerados por Web Audio API, sem arquivos de áudio pesados
- 📱 **Responsivo** — navegação adaptada para desktop e mobile
- ☁️ **Sincronização entre dispositivos** — progresso e preferências acompanham a jogadora em qualquer aparelho
- ♿ **Acessibilidade** — respeita a preferência de sistema por movimento reduzido (`prefers-reduced-motion`)

## Stack técnica

HTML, CSS e JavaScript puros (vanilla) — sem frameworks, sem build step. Hospedado gratuitamente no GitHub Pages. Sincronização de progresso via API do GitHub, sem backend dedicado.

## Status

🚧 Em desenvolvimento ativo. A trilha de conteúdo técnico, quizzes, glossário e demais módulos estão sendo construídos progressivamente.
